# amorwii

amorwii es una plataforma web para crear dedicatorias y detalles para eventos de forma elegante, rapida y profesional.

El proyecto esta inspirado en lovewi, pero con una arquitectura mas moderna y escalable para mejorar SEO, velocidad de carga, experiencia de usuario y mantenimiento a largo plazo.

Stack principal:
- Next.js + TypeScript
- Supabase (base de datos y autenticacion)
- Vercel (deploy principal)
